# React kluczowe koncepcje

Ćwiczenia zamieszczone w tym repozytorium wykonuję w ramach nauki React na podstawie książki „React – Kluczowe koncepcje” autorstwa Maximiliana Schwarzmüllera.
Repozytorium służy do dokumentowania mojej nauki, praktycznego przećwiczenia omawianych zagadnień oraz utrwalania najważniejszych koncepcji React.
